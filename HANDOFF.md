# HANDOFF — Журнал передачи и верификации ОТ-База

## Текущее состояние
- **Фаза**: Этапы P0/P1, Этап 5 (мульти-провайдер LLM + «Сгенерированные документы») и Этап 6 («Шаблоны» по разделам и таблицам, архивация при удалении вкладки, прямая вставка `Ctrl+V` из Excel) завершены; автотесты и сборка пройдены.
- **Ключевые артефакты сборки**:
  - `public/app.html` (автономный однофайловый бандл UI)
  - `public/initial_db.json` (актуализирован с категориями встроенных шаблонов)
  - `public/download/OT-Baza.exe` (x86-64 Win64 GUI PE32+ с встроенным локальным HTTP-сервером `127.0.0.1` и поддержкой подпапок `./documents/<Категория>/АРХИВ/<дд.мм.гггг>/`)
  - `public/download/OT-Baza-Windows.zip` (`OT-Baza.exe`, `app.html`, `data/ot_database.json`, `ИНСТРУКЦИЯ.txt`, `Запустить_ОТ_База.bat`)

## Что проверено в текущей среде (Linux container)
- **Проверка типов (`npx tsc --noEmit` / `npm run lint`)**: 0 ошибок.
- **Сборка веб-приложения (`npm run build` / `vite build`)**: успешно (включая `dist/app.html`, `dist/download/OT-Baza.exe`, `dist/download/OT-Baza-Windows.zip`).
- **Регрессионные автотесты (`npm test` / `vitest run`)**: 32/32 тестов пройдены (7 файлов: `storageService.test.ts`, `integrityService.test.ts`, `excelService.test.ts`, `documentGenerator.test.ts`, `portablePackageService.test.ts`, `llmProviders.test.ts`, `generatedDocsService.test.ts`).
- **Кросс-компиляция Windows (`python3 build_native_windows.py`)**: выполнена без единого предупреждения (`x86_64-w64-mingw32-gcc -Wall -Wextra -Werror -O2 -s -mwindows`), проверен заголовок `PE32+ executable (GUI) x86-64` и целостность ZIP-архива (`testzip() == None`).
- **Ограничение среды**: в Linux-контейнере отсутствуют ОС Windows, Wine и физические USB-накопители — живое исполнение обновлённого `OT-Baza.exe` на Windows выполняется на целевом ПК.

## Статус ручной проверки на Windows 10 / 11 и USB
- **Этапы 1–4 (базовый запуск `OT-Baza.exe`, USB, `Mutex`, `127.0.0.1`, PDF с кириллицей)**: подтверждено пользователем ранее.
- **Дополнительная проверка для Этапов 5–6 на целевой Windows 10/11**:
  1. **«Шаблоны» по разделам и вкладкам**: открыть «Документы -> Шаблоны» (видны разделы и все привязанные таблицы), затем открыть «Шаблоны» на панели любой вкладки (видны только шаблоны данной таблицы).
  2. **Удаление таблицы с шаблоном**: создать тестовую вкладку с шаблоном и удалить её — убедиться, что появляется предупреждение о связях/шаблонах и выбор «Да — переместить в архив» / «Нет — удалить всё».
  3. **Прямая вставка `Ctrl+V` из Excel**: скопировать 1 или несколько столбцов в Excel, кликнуть по ячейке на строке #1 и нажать `Ctrl+V` — убедиться, что данные вставляются в соответствующие столбцы ниже строки #1 и сдвигают нижележащие строки вниз; скопировать больше столбцов, чем создано в таблице — убедиться в чётком отказе.
