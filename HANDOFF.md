## 2. Фактическое состояние проекта

**Продукт.** «ОТ-База» — автоматизация документооборота специалиста по охране труда: событие жизненного цикла → пакет обязательств (документы + сроки) → контроль исполнения.

- **Модули (этапы).** 7 модулей = 7 вкладок: штатное расписание, сотрудники (базовые), инструктажи, медосмотры, СИЗ, СОУТ, несчастные случаи. Установка/снятие — «Вкладки → Модули этапов»; отключение скрывает вкладку, данные сохраняются. Новая база стартует с двух базовых модулей.
- **События.** Приём (8 требований), перевод (3), увольнение (3), несчастный случай (3). Идемпотентно по событию; уволенные исключаются из расчёта пакетов.
- **Матрица требований.** Учитывает должность и класс условий труда (медосмотр 2.0 — 24 мес., 3.x — 12 мес.; обучение руководителей — 36 мес.), у каждого требования указана нормативная база.
- **Документы.** 8 встроенных шаблонов (приказы о приёме/переводе/увольнении/ответственном, направление на медосмотр, карточка СИЗ, протокол знаний, акт о несчастном случае) + собственные `.docx`; пакетная генерация из карточки работника; реестр и архив версий; при подключённой папке — запись в `documents/<Категория>/`.
- **Хранение.** (1) рабочая папка через File System Access API (`data/ot_database.json` + бэкапы), (2) `localStorage`, (3) `OT-Baza.exe` с локальным сервером. Последний собирается только на Windows с MinGW-w64.
- **Интерфейс.** Liquid Glass + Bento: градиентный canvas, стеклянная оболочка, сайдбар 236/64 px, bento-дашборд «Главная», превью вкладок при наведении, режим эффектов `glass`/`reduced`; таблицы — на непрозрачной подложке.

**Артефакты (генерируются, в git не входят):** `dist/` (веб-сборка), `dist-offline/` (IIFE), `public/app.html` (офлайн-однофайловик), `public/download/*` (Windows-бинарники, здесь не собираются).

**Проверки на момент передачи:** `pnpm test` — **173/173** (19 файлов), `pnpm lint` (`tsc --noEmit`, strict) — 0 ошибок, `pnpm build` — успешно. Браузерные сценарии: приём → 8 требований → пакет документов; перевод/увольнение; модули; карточки/таблица; запись файлов в папку; 1440×950 и 1366×768, светлая/тёмная темы, 0 ошибок консоли.
