## 1. Общие нерушимые инварианты (проверяются на каждом этапе D-2 — D-6)

1. **Сохранность бизнес-логики и данных:**
   - Структура `DatabaseState`, `LegalEntity`, `Tab`, `Column`, `Row`, `DeadlineAppSettings` сохраняет 100% обратную совместимость.
   - Логика расчёта сроков, периодичности, рабочих дней (`holidays`), дедупликации toast (`shownToastKeysRef`) и `snooze` (`snoozedNotificationKeys`) работает идентично `T-45`–`T-49`.
   - Работают все режимы хранения (`native-fs` ./data/ot_database.json и `web-preview` localStorage), экспорт/импорт Excel/CSV, прямая вставка `Ctrl+V`, генерация DOCX/PDF (в т.ч. готовых `.docx`-шаблонов `T-44`), аудит связей и LLM-студия.
2. **Тестовая и сборочная чистота:**
   - `pnpm test` (`vitest run`): 100% прохождение без отключения существующих тестов.
   - `pnpm lint` (`tsc --noEmit`): 0 ошибок TypeScript.
   - `pnpm build` (`vite build`): успешная сборка.
   - В браузерных проверках: **0 `console.error`**, **0 `pageerror`**.
3. **Матрица разрешений, масштабов и тем (обязательная проверка для UI-этапов):**
   - Разрешения: **`1920×1080`**, **`1600×900`**, **`1366×768`**.
   - Масштабы Windows / DPR: **`100%`**, **`125%`**, **`150%`** (включая минимальный логический viewport `1366×768 @ 150%` ≈ `911×512` CSS px).
   - Темы: **светлая (`light`)** и **тёмная (`dark`)**.
   - Для всех комбинаций: `documentElement.scrollWidth <= documentElement.clientWidth` (нет горизонтального переполнения страницы), все ключевые кнопки доступны и не обрезаны, текст контрастен (`WCAG AA >= 4.5:1`).
