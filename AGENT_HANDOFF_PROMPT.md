ЧТО ЭТО ЗА ПРОДУКТ
Приложение для специалиста по охране труда. Оно снимает с него бумажную работу:
событие жизненного цикла работника → автоматический пакет обязательств (документы + сроки) → контроль исполнения.

- Интерфейс: Liquid Glass + Bento, сайдбар 236/64 px, bento-дашборд «Главная», превью вкладок,
